## Important limits

Dependency/format/type/export checks validate scaffolding only. Live Turso/PlanetScale transactions, Railway/Blacksmith execution, cross-process failover, stale-owner rejection, projection correctness, tenant isolation and load capacity are **not established**. All those gates require implementation and authorized provider environments.

Native Effect tsgo and Oxlint integration must demonstrate the deliberate failing diagnostic sentinel. A command that does not load the intended diagnostics is not an acceptable substitute. Failed checks must be fixed before the repository is treated as a working baseline.

A lockfile is supplied only if generated by a successful package-manager operation. No lockfile contents are fabricated. No accounts, cloud resources, secrets, repositories, deployments or published packages were created.
