# Security policy — setup stage

No production runtime or hosted service exists in this archive. Before public release, the owner must establish a real private vulnerability-reporting channel and support/version policy.

Do not post secrets, customer data or live exploit credentials in public issues. Use the repository owner's configured private security advisory mechanism once available. No contact address is invented here.

See docs/SECURITY.md and docs/SECURITY_THREAT_MODEL.md for the design and outstanding security gates.
