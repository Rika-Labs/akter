# Research evidence

`source-registry.json` and RESEARCH_SOURCES.md identify primary sources and pinned snapshots. `retrieval-summary.json` records automated HTTP/registry checks, not runtime validation. `effect-rule-inventory.json` captures the explicit diagnostics inventory and whether its extraction/config name could be verified. `toolchain.lock.json` records selected versions and registry availability.

Do not reinterpret a reachable page, current package version or source API as proof that the combined actor architecture works. Provider and runtime conformance is specified by validation gates. Full downloaded third-party pages/source trees are intentionally not redistributed.
