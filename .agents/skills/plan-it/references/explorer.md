# Brief for an explorer

Fill in the brackets and send one per slice, all at once, to fresh-context agents.

```text
Goal: <one sentence: what changes for whom>.
Your slice: <for example apps/docs, apps/cli, packages/akter, packages/cloud-api, tooling/conformance,
workflows, docs and skills>.
Don't edit anything. Find everything in your slice that must change for the goal, and everything that
would break or behave differently if it didn't: callers, types, RPC routes, actions and jobs, durable
formats, access checks, tests, seeded simulator fixtures, docs and skills that describe it.
Reply with a list: file:line, what must change, why, and how risky (low, medium, high). Then list what
you weren't sure about.
```
