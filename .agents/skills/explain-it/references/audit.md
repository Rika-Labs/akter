# Before sending

Run the audit in writing, in your notes or thinking, not by glancing. Fix every failure.

- **Trace.** Each trace step next to the source line that supports it, or "general knowledge". Label every
  general-knowledge step in the text.
- **Terms.** Each term next to the line where it is first used and where it is defined. The definition
  comes first, including in the lead, a diagram, a table, a path or a label.
- **Names.** The names used for each concept, lead included. Two names for one concept: pick one.
- **Claims.** Match each sentence to the source. Is any inference, illustration, attribution, universal
  claim, dependency, estimate or "all/none/the rest" unsupported or unscoped? Do the counts add up?
- **Lead.** Does it hold the verdict or count, each named case, and the largest blocker or first action?
- **Repeats.** Does any fact or grouping appear in two forms? Keep one.
- **Visuals.** The longest run of prose without a visual, table or list is under about 120 words. Each
  visual shows something the prose does not. Every label is a real name; numbers match the text.
- **Code.** Each snippet is copied or run, its output real, under about 15 lines, one idea, names real,
  terms defined before it.
- **Format.** Each bold span is a term at its definition. No em dashes, no "just".
- **Render.** View every generated image before sending.

## Fresh-reader check

Do not skip it or replace it with your own reread.

1. Start a fresh subagent. Give it only the finished text and the source, not your notes or these
   instructions.
2. Ask it to list every word it cannot follow, every term used before it is defined, every claim it
   cannot find in the source, and every place it had to reread.
3. Fix every item and run it again. Stop when a run returns nothing, or after three runs.

Without a subagent tool, reread as the reader and answer "why?" and "what do I do?" from the page alone.
