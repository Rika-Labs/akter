# M4: Operations, tenancy, and hosting

**Responsibility:** define the M4 slices, their order, and the exit test.  
**Authority:** delivery plan.  
**Owner role:** delivery/runtime lead.
**Change policy:** a change requires delivery lead sign-off.

M4 makes the framework operable in its three deployment shapes: embedded, served, and hosted ([vision](../vision/07-deployment.md)). It adds:

- readiness and bounded drain;
- observability;
- migrations, backup and restore;
- optional row-level security;
- operator authority;
- evolution of stored event and effect payloads;
- a single-region hosted edge;
- read-your-writes from replicas;
- parent-actor placement.

Multi-region placement and the cold tier each get an ADR here. They're built only if the delivery lead includes them; see [scope decision](#scope-decision).

The exit test is a rehearsal on the served chat room from M3:

1. deploy it;
2. drain a runner under load;
3. fail over the Postgres primary;
4. restore a backup;
5. show that no command ran twice or got lost.

1. **Wave 5 (during M2 and M3):** M4.1 is docs, so it starts early.
2. **Wave 7:** M4.2, M4.3, M4.4, M4.5, M4.7 and M4.11 run in parallel. They touch different subsystems.

The [M2 rules](M2.md#rules-for-every-slice) apply. Every operator-facing feature also documents its signal and its fix in [runbooks](../operations/runbooks.md). ## Slice details

**M4.2: drain.**

- **What it builds:** `RuntimeControl` from [ADR 0003](../decisions/0003-failure-scoping-drain-and-hosted-trust.md). Draining refuses new admission, lets in-flight turns finish until a deadline, and then interrupts them. Pending durable work stays recoverable. The outcome says whether the drain finished cleanly or hit the deadline.
- **Evidence:** the **Bounded graceful drain** check, and the row "Drain deadline expires", both on the multi-runner harness.

**M4.3: observability.**

- **What it builds:** runtime metrics for mailbox age, relay lag, receipt, event and outbox growth, pool waits, and activation counts. `durable defects list` reads defect spans from the telemetry exporter.
- **Evidence:** a span assertion for invariant O1.

**M4.4: migrations and restore.**

- **What it builds:** an expand-and-contract migration guide for framework and business tables, and a restore rehearsal on Postgres.
- **Evidence:** invariant D1, R5's restore cases, and the row "Restore, clock change, or version skew at the retry horizon".

**M4.5: row-level security.** Opt-in RLS policies on framework and owned tables, keyed by the transaction's tenant scope.

- **Evidence:** S2 with RLS on, and the support-matrix row "Tenant-scoped transactions".

**M4.6: operator authority.**

- **What it builds:** operator capabilities scoped by action and resource, audited repair intents, and `durable inspect Room/r1`.
- **Evidence:** the operator half of the **Hosted assertions and operator authority** check, and the row "Application credential attempts operator repair".

**M4.7: payload evolution.** Today a stored event that no longer decodes fails its query ([M1.5](M1.md)). Events and effect payloads get a declared migration chain, as state has.

**M4.8: hosted edge.**

- **What it builds:** the edge authenticates a request and issues a short-lived signed assertion bound to:
  - the actor;
  - the operation;
  - the command id;
  - the payload.

  Runners verify the assertion before admission.

- **Evidence:** the **Hosted assertions** check, and the row "Hosted assertion forged, expired, or bound to a different request".

**M4.9: read-your-writes.** A handle sends the highest commit version it has seen, and a replica answers only once it has caught up to that version.

- **Evidence:** Q1 and the **Read-your-writes** check against a real streaming replica.

**M4.11: parent-actor placement.** This is the third placement kind from [ADR 0006](../decisions/0006-scale-rules-placement-and-query-tiers.md).

- **Evidence:** the **Placement and single-shard paths** check for it.

**T10: Postgres failover drill.** A streaming replica is promoted under load. Commit-unknown outcomes resolve through receipts, and there's no duplicate or lost work.

**T11: M4 scale run.**

- flat latency at 10^5 and 10^7 stored actors on one Postgres;
- stored-actor overhead;
- backup and restore times;
- remote-user latency, only if M4.10 ships.

## Scope decision

[ADR 0005](../decisions/0005-turn-latency-batching-and-regional-placement.md) and [ADR 0006](../decisions/0006-scale-rules-placement-and-query-tiers.md) describe regional placement and a cold tier for hosted deployments. Both are large. They matter only for remote users and very large idle fleets.

The recommended default:

- M4 writes both ADRs (0025 and 0026) and builds neither M4.10 nor M4.12.
- The single-region hosted edge (M4.8) and read-your-writes (M4.9) ship in M4.
- Regions and the cold tier move to their own milestone once hosted usage asks for them.

The delivery lead confirms or changes this before wave 7 starts.

## Excluded

- Neki-specific gates are M5.
- Tenant moves between regions are in scope only if M4.10 is.
- Automatic hot-tenant detection is excluded, because moves are operator actions ([ADR 0011](../decisions/0011-direct-commands-outbox-and-performance.md)).

```

```

### What the rehearsal proves

```ts
it.cluster("drains a runner under load without losing or repeating a command", { runners: 3 }, ...)
it("resolves commit-unknown turns through receipts after the primary fails over", ...)          // T10
it("restores a backup without reopening expired command ids or dropping pending intents", ...)  // M4.4, D1
it("rejects an edge assertion bound to a different payload before admission", ...)              // M4.8
```

## Exit criteria

M4 is complete when all of these hold:

- Every included slice is merged with its cases passing in CI.
- The rehearsal (drain, failover, restore) passes and its results are recorded.
- The runbooks cover every failure M4 claims to recover from.
- The support matrix records migrations and restore, tenant-scoped transactions, and the hosted single-region path on Postgres.

Neki remains gated until M5.
