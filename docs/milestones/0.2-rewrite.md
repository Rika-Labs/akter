# The 0.2 rewrite: E0–E8

The rewrite runs in place on `rewrite/0.2`. Every milestone requires failure evidence for its durable transitions; a type, design page, or passing happy-path example is not an exit gate.

| Milestone | Scope                                                                              | Evidence/status boundary                                                                                       |
| --------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| E0        | Accepted actor, store, authority, job, RPC, history, and operator decisions        | ADRs 0124–0137 and 0.2 contracts define the target                                                             |
| E1        | Schema contracts, synchronous actions, discard, identity, seeded simulation        | [Local execution evidence](../verification/e1-execution.md)                                                    |
| E2        | Bucket log, epochs, checkpoints, recovery, build matching, drain                   | [Local recovery evidence](../verification/e2-recovery.md); no production-provider claim                        |
| E3        | Membership, mTLS routing, cross-shard sends, timers, cron, handoff                 | [Cluster evidence](../verification/e3-cluster.md); five-second move target not met under defaults              |
| E4        | One RPC group, WebSocket JSON, HTTP NDJSON, Effect client, sessions                | [Client and serve evidence](../verification/e4-rpc-serve.md)                                                   |
| E5        | Shard-journaled jobs, steps, retries, deadlines, failure route                     | [Job evidence](../verification/e5-jobs.md); external idempotency remains necessary                             |
| E6        | Page-backed lists, retained history, fenced GC, forks                              | [Local page/history evidence](../verification/e6-pages-history.md); actor-only forks and provider/50 GB limits |
| E7        | Durable scalar indexes, id-only find, audited operators, filesystem dev, telemetry | Current integration work; operator grants/audits and index persistence need their own evidence                 |
| E8        | Hosted stores, credentials, wake-up, rollout, metering, approved pricing/quotas    | Private platform evidence and provider validation; not established by framework tests                          |

The early E7 `akter storage check` probes are recorded in the [provider matrix](../verification/store-providers.md). MinIO is local S3-compatible evidence only; R2, Tigris, and AWS S3 remain unestablished without their own runs.

The release swap requires green current-head checks, compatible published package units, a coherent documentation/navigation set, and the outstanding provider/hosted gates. No migration from 0.1 is offered.
