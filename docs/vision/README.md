# Product vision

Akter makes durable stateful applications feel like ordinary typed application code: one actor address, synchronous actions, Effect jobs, and live reads. The 0.2 product uses a bucket-backed log rather than application-owned relational tables.

These pages state intent, not a provider certification or release promise. [Contracts](../contracts/README.md) define guarantees and [verification](../verification/README.md) supplies evidence.
