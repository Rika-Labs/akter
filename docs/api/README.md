# Public APIs

Akter 0.2 has one actor contract, one Effect client, one `/rpc` group, and one store abstraction. Start with the [server API](01-server-api.md), then read [context capabilities](02-context.md) and the [TypeScript SDK](03-typescript-sdk.md).

The [CLI](06-cli.md) covers cloud commands, local development, storage checks, and audited operator reads. Cloud API pages describe hosted HTTP contracts and do not imply that hosted pricing or provider support is complete.
