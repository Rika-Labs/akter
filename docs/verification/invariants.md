# Invariants

**Responsibility:** connect contracts to named tests.  
**Authority:** verification.  
**Owner role:** verification/reliability.
**Change policy:** a change requires the conformance suite to be updated in the same change.

Each invariant MUST have a named executable case in `describeConformance` or an integration suite. PGlite covers fast transactional cases; real Postgres covers contention; Neki covers pinning, locality, and outbox delivery; multi-runner and served HTTP harnesses cover routing and edge attribution.

| ID  | Invariant                                                                                                                                                                | Required evidence                                                                                                                                                                                                                                                                |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A1  | Only the current generation commits.                                                                                                                                     | Two contenders plus stale generation; real Postgres and Neki locking gates.                                                                                                                                                                                                      |
| A2  | Request/reply never crosses a turn boundary.                                                                                                                             | Captured handle dies with the required message and all writes roll back.                                                                                                                                                                                                         |
| A3  | Off-turn contexts cannot mutate durable actor data.                                                                                                                      | Type tests plus runtime rejection of unsupported mutation paths. `actor_connections` is session data with listed, fenced writers; a stale generation cannot write a connection's session.                                                                                        |
| A5  | A turn-minted child is created only by its parent's same-turn intent.                                                                                                    | Crash before COMMIT, commit-unknown, and a client racing the creating intent: one child per derived id, never created by any other caller (ADR 0025, target).                                                                                                                    |
| T1  | One framework-owned transaction contains every turn consequence.                                                                                                         | Before-COMMIT crash leaves no receipt, state, row, event, intent, or effect.                                                                                                                                                                                                     |
| T2  | Deterministic defects roll back without evicting the actor.                                                                                                              | Size, decode, and internal-caller cases assert `Die`, a span carrying the cause, and residency.                                                                                                                                                                                  |
| R1  | One retained command id and payload creates one transition.                                                                                                              | Concurrent duplicates, caller retry after runner loss, and after-COMMIT retry replay one receipt.                                                                                                                                                                                |
| R2  | Reusing a command id for different input is a conflict.                                                                                                                  | `ActorError.reason` is `CommandConflict`; no handler run.                                                                                                                                                                                                                        |
| R3  | Declared failures replay unchanged.                                                                                                                                      | Same class and payload through Effect, HTTP, and Promise client.                                                                                                                                                                                                                 |
| R4  | Receipt access never widens deduplication identity.                                                                                                                      | Original caller with current access or scoped operator reads outcomes; other callers cannot read or reexecute; rotated credentials preserve logical caller identity.                                                                                                             |
| R5  | Expired external command identities cannot execute anew.                                                                                                                 | Boundary, prune/retry race, crash/restart, clock/version/policy change, and restore cases reject old ids while preserving accepted internal recovery; clients never silently remint.                                                                                             |
| M1  | Rolled-back intents are never delivered.                                                                                                                                 | Intent rollback gate on `actor_outbox`.                                                                                                                                                                                                                                          |
| M2  | Outbox delivery preserves one logical intent.                                                                                                                            | Crash/restart around sender COMMIT, receiver commit, and outbox row deletion; stable intent id and receiver receipt replay.                                                                                                                                                      |
| E1  | Events exist only for committed turns and remain cursor ordered.                                                                                                         | Rollback, replay, retention-gap, and multi-runner feed cases.                                                                                                                                                                                                                    |
| E2  | Each committed source event takes effect exactly once per active subscription, in source cursor order, or is reported as a gap, except the counted cases ADR 0026 lists. | Relay kill before and after subscriber commit, stale redelivery, receipt pruning, rollback, and retention-gap cases in `conformance/subscriptions.ts`.                                                                                                                           |
| S1  | State migration is complete and atomic.                                                                                                                                  | Seed old row, upcast in next turn, commit current shape; invalid chain rejected.                                                                                                                                                                                                 |
| S2  | Every row remains tenant scoped.                                                                                                                                         | Cross-tenant reads/writes, workflow equal-key isolation, optional RLS cases.                                                                                                                                                                                                     |
| C1  | Parked sockets survive activation hibernation and owner loss.                                                                                                            | Connection park gate, restored session, resumed flag, wake on open or frame on the current owner, broadcast from a command, intent, or timer that woke runner B to a connection held on runner A, graceful move and owner kill with in-place resync on the multi-runner harness. |
| W1  | Workflow identity includes owner and tenant.                                                                                                                             | Equal keys across tenants/owners never join; resume preserves attribution.                                                                                                                                                                                                       |
| W2  | Owner-event waiting has no registration gap.                                                                                                                             | Event in the start-to-wait race resolves the durable wait.                                                                                                                                                                                                                       |
| G1  | Exactly one singleton is resident cluster-wide.                                                                                                                          | Two runners, one background loop, one cron tick, movement after runner kill.                                                                                                                                                                                                     |
| H1  | HTTP caller identity is per request.                                                                                                                                     | Concurrent distinct tokens differ; missing credentials fail before any turn.                                                                                                                                                                                                     |
| H2  | Revocation removes external access, not accepted obligations.                                                                                                            | Deny new admissions and result reads; resume accepted work with attribution; sessions close at `policy.reauthorizeEvery` from the last success, parked and idle included, with buffered frames discarded; cancellation remains explicit.                                         |
| O1  | Observability names are stable.                                                                                                                                          | Span assertion for `durable-actors.<Actor>/<Command>` and correlated command id.                                                                                                                                                                                                 |
| P1  | Unknown provider outcomes are not silently treated as failure.                                                                                                           | Provider success followed by lost acknowledgment preserves ambiguity or reconciles through proven idempotency.                                                                                                                                                                   |
| P2  | A cancelled effect is never retried and never silently dropped.                                                                                                          | Cancel before claim, during an attempt, after a lease loss, and racing the claim: a never-attempted effect never runs, and an attempted one is reported once, as `Unknown` and ambiguous when the provider may have applied it (ADR 0024, target).                               |
| A4  | A foreign mutation cannot partially succeed.                                                                                                                             | Mixed-owner writes, joins, upserts, cascades, and raw SQL are rejected or enforced according to the supported query matrix.                                                                                                                                                      |
| D1  | Restore does not create dual writable authority.                                                                                                                         | Real-backend restore/restart tests preserve fences, receipt horizons, pending intents, and provider reconciliation state.                                                                                                                                                        |

| M3 | A direct command is durable only once its receipt commits. | Runner loss before commit leaves no receipt or consequence; the caller's retry with the same id executes once. |
| B1 | Pipelined batches expose nothing before their own commit. | Batch N+1 replies, broadcasts, and outbox rows stay hidden until batch N+1 commits; a failed batch N discards N+1's staged work. |
| C2 | Commutative reducer merging equals sequential application. | Generated inputs satisfy `reduce(reduce(s, a), b) = reduce(s, combine(a, b))`; one receipt per original command id. |
| C3 | Optimistic client state converges to committed state. | Browser handle rolls back failed reducers and matches committed state after every receipt. |
| Q1 | Queries observe the caller's own writes. | Replica or edge answer waits for or falls through past the handle's last-seen commit version. |
| C4 | Live output is never silently lost. | Connection buffer overflow, a broadcast sequence gap, an owner killed at every point between commit and flush (mid-turn, mid-batch, before its first message to a holder, racing a handler broadcast; randomized), an unreachable holder, a snapshot/live race in `open`, a stalled stream, and an ended activation each deliver everything or give the client a cursor from which event replay recovers every event-backed frame, and tell it to reload state for the rest. |
| C5 | Executor progress is never authoritative (target, [ADR 0030](../decisions/0030-executor-progress-frames.md)). | Dropping every progress message leaves receipts, state, events, outbox rows, routes, and outcomes unchanged; no progress frame follows its effect's route or cancellation, or arrives more than 5 seconds after a route-less settle; a loss before a later delivered frame of the attempt is a visible `seq` gap; progress never closes a session. |
| X1 | Simulation failures reproduce from their seed. | `ActorTest.simulate` reruns a failing seed to the same fault schedule and outcome. |
External replay and conflict cases assume an unexpired command identity and current receipt-access authorization. Rejected access or expiry must not invoke the handler. Trusted internal recovery follows the retained obligation rather than rechecking the originating caller as a new external admission.

M1, M2, and M3 for relay-delivered commands have single-runner, same-shard evidence from M1.6 on PGlite and Postgres, with SIGKILL cases on Postgres; the case names are in the [conformance ledger](01-conformance.md#outbox-intents-and-timers-m16). Cross-shard, cross-region, and multi-runner delivery remain unverified.

A1 has evidence with two real runners from M2.1 on Postgres: a stale activation fails its fence after another runner commits, and events stay gap-free while two runners race for one actor. M3 has evidence across a runner kill: a turn killed before COMMIT leaves no receipt or consequence and the caller's retry with the same id commits once on the new owner, and a turn killed after COMMIT but before its reply is replayed from its receipt on the new owner rather than run again. The case names are in the [conformance ledger](01-conformance.md#multi-runner-harness-m21).

W1 and W2 are specified further by [ADR 0022](../decisions/0022-workflow-engine-storage-and-version-markers.md): a wait sees the owner's events after its execution's cursor, including events of the turn that started it, and the cases that prove W1, W2 and H2 for workflows are named in the [conformance ledger](01-conformance.md#implementation-decision-checks).

P1 has single-runner evidence from M1.7 on PGlite and Postgres: a lost result reruns the executor under the same effect id, and a dead letter reports `ambiguous` unless the last attempt failed with a typed error; the case names are in the [conformance ledger](01-conformance.md#effects-with-routes-m17). Provider-specific reconciliation remains per adapter.

The mapping from these invariants to normative guarantees is in [runtime contracts](../contracts/README.md); crash expectations are in the [failure matrix](02-failure-matrix.md).

R5 with automatic pruning (boundary, prune/retry race, crash inside a sweep, and restart) is executed in `conformance/retention.ts` and `crash/retention.test.ts`; its restore and version-skew cases wait for M4.
