# T7: the seed matrix at 10,000 seeds (2026-10-14)

**Responsibility:** record the dated 10,000-seed run that ADR 0124's registry requires before 0.2.0.  
**Authority:** dated verification evidence; simulator only.  
**Owner role:** runtime and reliability.

## What ran

The `seed matrix` test in `packages/akter/src/testing/simulation.test.ts`, "conserves money and delivers every send and timer exactly once across N faulted seeds", with `AKTER_SIMULATION_SEEDS=10000`. Each run starts twelve concurrent transfers among five accounts on the memory bucket, crashes every shard partway through, and injects crashes, lost responses, outages and slow log calls. Run `n` uses seed `SIMULATION_SEED_BASE + n`, so this run covered seeds `0x5eed0000` through `0x5eed270f` (1592590336 through 1592600335). The default CI matrix still runs the first 1,000 of them.

For every seed the test asserts that money totals 500, received equals sent, there is one audit timer per sent transfer, and the number sent lies between the successful transfers and the successful plus unknown ones. `Simulation.settle` also checks I1–I6 and I9 against the bucket after every run. Across the whole matrix it asserts that refusals, crashes, lost responses and outages each happened at least once. No invariant, assertion or fault was changed for this run.

## Commands

From the repository root at commit `e8e8b020d16046b7469af241b9ac40f7450261ab` (a clean tree), on macOS 26.6.2 on an Apple M5 Max (18 cores):

```sh
cd packages/akter && AKTER_SIMULATION_SEEDS=10000 bun --bun ../../node_modules/vitest/vitest.mjs run --root ../.. packages/akter/src/testing/simulation.test.ts -t "conserves money" --reporter=verbose
AKTER_SIMULATION_SEEDS=10000 node node_modules/vitest/vitest.mjs run packages/akter/src/testing/simulation.test.ts -t "conserves money" --reporter=verbose
```
